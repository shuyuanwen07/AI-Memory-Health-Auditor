1. Summary
We implement a source-grounded audit workflow for conversational memory use. The
system extracts candidate memories, requests source review, generates contextual
probes, executes a controlled target with configurable memory policies, and reports
evidence-backed pass/fail/uncertain judgments in four dimensions. Real language
models may be selected through OpenRouter or locally through Ollama. Model weights
remain unchanged. The controllable intervention is the surrounding memory policy.
A newly controlled evaluator comparison scores the same saved reply using rule and
hybrid review. Independent human validation is required before claiming reliable
failure detection or useful general repair. INSERT the principal measured result
only after a frozen independent evaluation.

2. Problem, users, scope and requirements
A conversational assistant may retain outdated facts, choose an unsupported side
of a conflict, lose task requirements or apply a general preference in the wrong
context. A correct reply alone cannot establish that relevant memory was delivered
or used. Developers need questions, source evidence and traceable diagnoses that
help identify failure families and evaluate general fixes.
Our intended user imports authorised histories and reviews proposed ground truth.
The supported assessed scope is a controlled memory system with a fixed language
model, not model training or universal access to another vendor's private memory.
Functional/non-functional implementation and evidence limits are mapped in
REQUIREMENTS_TRACEABILITY.txt. INSERT approved proposal citations and human-verified
source requirements. External Agent integration is optional retained infrastructure.

4. Architecture and data flow
React/TypeScript with Ant Design provides intake, review, audit, comparison and
research screens. FastAPI/Pydantic validates stage contracts. PostgreSQL/SQLAlchemy
stores ordered source histories, reviewed facts, frozen run configuration, canonical
questions, target answers, evaluations and separate human labels. Alembic manages
schema changes. Providers, prompts, policy versions and configuration fingerprints
are recorded. ARCHITECTURE.md contains the component/data-flow diagram.
Reviewer ground truth is distinct from target-private stored memories. The target
writer ingests authorised history and retrieval selects context under frozen policy.
Input receipts distinguish stored, retrieved and supplied evidence. Sending a memory
does not establish causal reliance. Source-linked evidence remains inspectable after
shared-answer review without inventing a new retrieval event or model request.
Failure paths include invalid structured model replies, unavailable providers,
rejected questions, interruption, cancellation, configuration drift and absent traces.

5. GenAI engineering
Extraction and generation use structured contracts and source IDs. Human review is
required to confirm proposed facts/relationships and question validity. Rule review
checks executable constraints; a configured LLM judge supplies semantic assessment.
Invalid semantic outputs and incompatible rule/semantic conclusions abstain safely.
The exercised test dimension is distinct from an observed source-supported failure
category. Target, extraction, test-generation and judge provenance are recorded
separately; the three-method comparison does not isolate extraction quality.
Rule-only and hybrid comparisons now reuse identical model-generated questions and
saved target replies per target/policy/repetition. Source receipts make this control
verifiable. Older separately executed results remain exploratory. Reused replies
are not independent samples and incur no second target call; semantic judge calls
still have their own usage and latency. Failure examples must include the complete
reply, expected behaviour and exact source support, not isolated keywords.

8. Reflection and limitations
Rule judgments remain bounded by lexical/structural detection. Semantic judges can
share target biases and generate unsupported reasoning. Source-ground-truth mistakes
propagate into tests and expected behaviour. Abstention selection changes decided
coverage. Blind review reduces displayed system-label anchoring but cannot guarantee
reviewers never saw an earlier report; record reviewer independence truthfully.
Exact source-overlap rejection does not prove semantic/template independence. Local
small-model results do not establish all OpenRouter model performance. Synthetic
small pilots and compatible-layout samples do not establish general benchmark or
market superiority. Formal validity needs independent human evidence and diversity.
