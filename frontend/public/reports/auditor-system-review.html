真实界面完整流程

合成对话 → 本地抽取 → 审核 → Qwen API → 判分 → 实际发送追踪 → PostgreSQL 保存 → 实验导出。两题中一题失败：位置记忆存在于存储，但检索并未发送；Qwen 回答“没有足够信息”，系统正确显示失败与零条输入。导出文件全部摘要一致。
